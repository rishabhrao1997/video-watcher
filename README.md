# SKILL: let Claude Code watch any video

Free, open-source skill by bradautomates: github.com/bradautomates/claude-video

Install (Claude Code in a terminal):
  /plugin marketplace add bradautomates/claude-video
  /plugin install watch@claude-video
(Or in Claude Desktop → Customize → Plugins → Add marketplace → paste the GitHub URL → install Watch. Use a Code session.)

Then ask:
  Watch this reel and tell me its hook, every cut, and why people kept watching: <link or file path>

Notes: Instagram links need you to be logged in (or download the reel and give Claude the file path). Videos without captions need a transcription option (local WhisperX is the private one).
